# Pandas Basics Notebooks

This repository contains beginner-friendly Jupyter notebooks to learn and practice **Pandas**, one of the most powerful Python libraries for data analysis.

## Contents
1. **Series** – Creating and working with Pandas Series.
2. **DataFrames** – Creating DataFrames, indexing, selection, adding/removing columns, conditional selection.
3. **Missing Data** – Detecting, removing, and filling NaN values.
4. **Merging, Joining & Concatenation** – Combining multiple DataFrames.
5. **GroupBy & Aggregation** – Summarizing data with group operations.
6. **Pivot Tables & Crosstabs** – Reshaping and summarizing data.
7. **Operations** – Basic operations, applying functions, and custom transformations.
